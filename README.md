# Typerfy — Type Garden

An interactive generative typography and botanical canvas experience. As you type, organic stems, leaves, flowers, and marine life flourish out of the letters with physics, spring damping animations, and live interactive creatures.

## Features

- **🌸 Rose Garden**: Organic curving vines, thorns, serrated leaves, and multi-layered blooming spiral roses with butterfly visitors.
- **🎋 Sakura Zen**: Woody bonsai branches, delicate 5-petal cherry blossoms with golden stamens, and fluttering red dragonflies.
- **🌊 Coral Abyss**: Deep sea kelp, 12-tentacle glowing sea anemones with pearls, and translucent jellyfish visitors.
- **Type Mode**: Real-time typing, word-wrapping, space cutting, backspace withering, and cursor force fields.
- **Poster Mode**: 1080×1080 animated loops with multiple motion presets (Breathe, Grow & wither, Typed, Gust, Reach, Scatter, Visitor).
- **Exporting**: Export high-resolution PNG, SVG, MP4/WebM video loops (30 fps), and ZIP frame sequences.

## Getting Started

1. Start the local server:
   ```bash
   node server.js
   ```
2. Open [http://localhost:3001/](http://localhost:3001/) in your browser.
